        02 · Espaço interno
        
Padding — sintaxe shorthand

        
O padding aceita de 1 a 4 valores. Clique em cada shorthand para ver quais lados são afetados.

SintaxeLados afetados

              
                
1 valorTodos os 4 lados iguais

                
2 valoresVertical · Horizontal

                
3 valoresTop · Horizontal · Bottom

                
4 valoresTop · Right · Bottom · Left (sentido horário)

              
            

          

          
💡 Importante: o padding não aceita valores negativos e herda o background-color do elemento.

        04 · Contorno sem afetar o layout
        
Outline

        
O outline é desenhado por fora do elemento e não ocupa espaço no layout — diferente da border. Clique (ou use Tab) nos botões abaixo: o vizinho nunca se move.

      

      

        

          
          
        

        
♿ Acessibilidade: nunca remova o outline sem substituí-lo por outro indicador visual de foco (WCAG 2.4.7) — ele é essencial para navegação por teclado.

Nível 3 — centralizar com margin: auto

          

            
.container { width: 800px; margin: 0 auto; }

          

          

            Ver CSS
            
.container {
  width: 800px;
  margin: 0 auto;
  padding: 20px;
  border: 1px solid #E2E8F0;
  background-color: #F8FAFC;
}

          

        


        

          
Nível 4 — box-sizing: border-box

          

            
width: 300px total
(padding e border incluídos)

          

          

            Ver CSS
            
*, *::before, *::after { box-sizing: border-box; }

.caixa-border-box {
  width: 300px;   /* tamanho total sempre 300px */
  padding: 30px;  /* incluído no width */
  border: 5px solid #F59E0B;
  /* content = 300 - 30*2 - 5*2 = 230px */
}
